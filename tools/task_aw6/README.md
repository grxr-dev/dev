# AW6 captured-state reconciliation (ROM-free only)

No installer, activation selector, game launcher, interpreter or guest bus is
provided here. Existing AU capture-only guards remain unchanged and deny AX.

`prefix.h` binds the exact AW5 canonical identity and every mandatory logical
field. It classifies the preserved Tier-3 hint, parked ARM7 HALT/debt, RTC phase,
timers and actual cap without rewriting them. It constructs a separate 11-step,
69-observation plan; it does not alter AW4's historical conditional plan. The
ledger checks full state, immutable projection, expected evolution, journal,
order, metadata, chained hashes and prospective guards. No protected field is
dropped. `controller.h` is an uninstalled diagnostic contract with nonreturning
success/failure disposal, not authorization to execute guest instructions.

`source_rail.h` is **test-only**. `check.py` extracts small current runtime source
bodies into an ignored build include and compiles them on synthetic scalar
objects initialized from AW5's saved canonical observation. The divider write
model invokes no guest/MMIO ABI. Its journal calls use the actual AW3 journal
implementation. RTC due, timer overflow, ARM7 wake, slice hint, reschedule,
publisher, debt-take, refill and cycle-combine bodies come from checked source.
CP15 classification uses the existing AW2 copied-state evaluator. This is not a
new actual-provider/interpreter/physical-divider execution claim.

From a checkout containing the authoritative AW5 commit and these helpers:

```powershell
python tools/task_aw6/check.py --out local/task-aw6/new-certification
python tools/task_aw6/certify.py --evidence local/task-aw6/new-certification --out local/task-aw6/new-static-certificate.json
```

The check opens only source, build metadata and retained scalar/hash audit
evidence. No ROM/save/checkpoint file is opened. Prior evidence and runner source/
executables are hashed before/after. The task-wide live-attempt lock is preserved.
Positive and negative source/model children exercise audit disposal and tail
sentinels. Full candidate dispatch remains unavailable.

The static reduced-prefix certificate is for exactly the observed profile. It
does not make the existing runner executable past AU, authorize a replay, admit
the 12th instruction or substitute a synthetic manifest. A separately reviewed
guarded ownership integration and later explicit execution authorization are
still required before any dynamic prefix run.
