# Brain Age DS recomp research

ROM-free research and tooling for investigating a native recompilation of **Brain Age: Train Your Brain in Minutes a Day! (USA Rev 1)** using `RetroPortingToolKit/ndsrecomp`.

## Rules

- No commercial ROMs, extracted ARM binaries, save files, BIOS/firmware dumps, or copyrighted game assets are committed here.
- ROM-derived metadata such as hashes, addresses, sizes, and analysis notes are allowed.
- Current upstream baseline: `RetroPortingToolKit/ndsrecomp` commit `3a57236bb23d25dcb4caad7d58d733311062ff5e` (2026-10-04).
- Exact supported ROM SHA-1 for research: `b8a105bacc3234dede8d4465df0869f2b922a0e2`.

This repository is maintained through ChatGPT's connected GitHub tooling as a working notebook/scaffold for the project.
